# Linux Production Monitoring

A hands-on Linux and Bash project for monitoring application processes and practicing common production support troubleshooting tasks.

## Project Objective

The goal of this project is to simulate basic Application/Production Support activities on a Linux system.

The project focuses on monitoring a running application process, collecting system and process metrics, detecting application failures, and using Linux commands and Bash scripts to investigate application health.

```markdown
## Planned Monitoring Features
The monitoring script collects and displays:

- Application PID
- CPU utilization
- Memory utilization
- Virtual memory (VSZ)
- Resident memory (RSS)
- Process elapsed time
- Thread count
- Open files
- Network connections
- Disk I/O

Additional monitoring and troubleshooting capabilities will be added as the project develops.
